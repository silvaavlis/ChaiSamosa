
A full-stack app using MERN stack for managing student team members.

## Features
- Add members with image upload
- View all members
- View individual member details

## Tech Stack
- React.js, Node.js, Express.js, MongoDB

## Run Instructions
1. `cd backend && npm install && node server.js`
2. `cd frontend && npm install && npm start`

## API Endpoints
- `GET /api/members`
- `GET /api/members/:id`
- `POST /api/members`
